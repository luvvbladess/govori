# Дизайн: веб-переводчик (мобильный, с голосом и аккаунтами)

Дата: 2026-07-14
Источник требований: `translator-mode-web-spec.md` (контракт API и модели зафиксирован там и не дублируется здесь).

## Цель

Мобильно-ориентированный сайт — двусторонний ИИ-переводчик «русский ↔ язык собеседника»
по правилам из `translator-mode-web-spec.md`. Добавляется поверх спеки: полноценные
аккаунты пользователей и голосовой ввод/вывод с первой версии.

## Стек

- **Backend:** Node.js + Express, один процесс отдаёт и API, и статику фронтенда.
- **Frontend:** ванильный HTML/CSS/JS, без сборки и фреймворков.
- **БД:** SQLite-файл (`data/app.db`) через `better-sqlite3`.
- **Сессии:** `express-session` + `connect-sqlite3` (сессии в той же SQLite-базе), кука.
- **Пароли:** `bcrypt`.
- **Перевод:** OpenAI Chat Completions API. Модель берётся из `TRANSLATOR_MODEL`
  (по умолчанию `gpt-4o-mini`), ключ — из `OPENAI_API_KEY`. Вызывается только с сервера.
- **Голос:** браузерный Web Speech API — `SpeechRecognition` (STT) и `speechSynthesis` (TTS).
  Без дополнительных бэкенд-вызовов и внешних сервисов.
- **Деплой:** Ubuntu VPS, Node-процесс, TLS терминируется на Cloudflare перед origin.

## Данные

Таблица `users`:

```
id              INTEGER PRIMARY KEY
email           TEXT UNIQUE NOT NULL
password_hash   TEXT NOT NULL
target_language TEXT NULL        -- например "Китайский"; см. TranslatorSession в спеке
created_at      TEXT NOT NULL
```

`target_language` — это ровно `targetLanguage` из контракта спеки, но привязан к
аккаунту, а не к анонимной сессии: переживает вход с любого устройства.

Таблица сессий управляется `connect-sqlite3` автоматически (стандартная схема пакета).

## API

### Аутентификация

- `POST /api/auth/register` `{email, password}` → создаёт пользователя, хеширует пароль
  через bcrypt, открывает сессию. 409, если email занят.
- `POST /api/auth/login` `{email, password}` → проверяет пароль, открывает сессию. 401 при неверных данных.
- `POST /api/auth/logout` → закрывает сессию.
- `GET /api/auth/me` → `{email, targetLanguage}` при активной сессии, иначе 401.

Все `/api/translator/*` требуют активной сессии (401 без неё).

### Переводчик

- `POST /api/translator/translate` — контракт запроса/ответа и коды ошибок ровно как в
  `translator-mode-web-spec.md` (раздел «Контракт backend API»). `targetLanguage` сервер
  читает из `users.target_language` текущего пользователя, клиенту не доверяет.
- `POST /api/translator/set-language` `{language}` — явная смена языка кнопкой
  «Сменить язык» в UI. `language` валидируется по фиксированному списку ниже,
  пишется напрямую в `users.target_language`. 400 при языке не из списка.

маркировка модели (`detected_lang`/`new_target_lang`) как есть.

## Голос

**STT (голос → текст):** одна кнопка микрофона. `SpeechRecognition.lang` по умолчанию —
код текущего `targetLanguage`, если он задан, иначе язык браузера. Рядом — переключатель
«Русский / язык собеседника» для ручной коррекции языка распознавания (автоматическое
определение языка речи Web Speech API не поддерживает). Распознанный текст попадает
в поле ввода для проверки перед отправкой — не отправляется автоматически.

**TTS (перевод → голос):** кнопка воспроизведения (🔊) на каждой карточке перевода,
запускает `speechSynthesis` с `utterance.text = voiceText` и `utterance.lang`, взятым
из кода языка результата. Воспроизведение только по нажатию — без автовоспроизведения.

## Экраны (мобильный интерфейс)

1. **Вход/регистрация** — одна форма (email + пароль) с переключателем режима.
2. **Переводчик** (после входа):
   - Верхняя закреплённая полоса: индикатор пары (`Русский ↔ Китайский` /
     `Язык собеседника не задан`) + кнопка «Сменить язык».
   - Прокручиваемая лента карточек «Оригинал» / «Перевод» с подписанным языком
     и кнопкой 🔊 на каждой карточке.
   - Нижняя закреплённая панель: текстовое поле, кнопка микрофона, кнопка отправки.
     Крупные touch-таргеты, отступы под safe-area (iOS notch/home-bar).

## Обработка ошибок

Ровно по контракту спеки: `TARGET_LANGUAGE_REQUIRED`, `TRANSLATION_FAILED` с одним
повтором при неверном алфавите результата. Клиенту никогда не отдаётся сырой ответ
провайдера или ключи API. Лимит длины реплики — 6000 символов. Rate limit на
`/api/translator/translate` через `express-rate-limit`, ключ — ID пользователя
(эндпоинт всегда за аутентификацией, IP как ключ не нужен).

## Тесты

Один файл `test/translator.test.js` на `node:test` + `assert` (без фреймворка),
покрывающий 9 сценариев из раздела «Обязательные тесты» спеки. Вызов OpenAI
подменяется стабом/моком — тесты не должны обращаться к реальному API.
