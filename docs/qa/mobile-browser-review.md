# Мобильная проверка — 11 октября 2026

Проверен опубликованный https://lexiqs.space во встроенном браузере Codex. Проверка использует размеры viewport, а не физический телефон или эмуляцию Safari. Применены impeccable (audit, craft-floor) и review-animations.

## Проверенные сценарии

- 390×844: основной экран, регистрация, создание общей беседы, приглашение, ввод длинной реплики, настоящий перевод, получение ответа другого участника через отдельную API-сессию.
- 320×568: общая история с длинными сообщениями, панель участников, приглашение, ввод и кнопки. После исправления ширина страницы ровно 320 px; кнопки приглашения и выхода находятся на одной высоте; панель занимает 61 px. Все видимые элементы управления не меньше 44×44 px.
- 390×420: сокращённая высота окна; при закрытой ссылке приглашения область истории составляет 95 px, ввод доступен.
- 844×390: альбомная ориентация, основной экран и открытие истории. Переполнения по ширине нет, кнопки находятся внутри окна, нижняя панель заканчивается на 390 px.
- Светлая и тёмная темы; переключение языка интерфейса RU↔EN обновляет уже существующие карточки. Выбор языка и история корректно открываются и закрываются.
- Во время регистрации и перевода отображается занятость; после завершения управление восстанавливается. Общая история восстанавливается после перезагрузки.

Ошибок JavaScript в проверенных сценариях не обнаружено.

## Исправления по результатам проверки

| Было | Стало | Причина |
| --- | --- | --- |
| На 320 px «Выйти» переходила на отдельную строку | Статус переносит текст внутри доступной ширины; обе кнопки остаются рядом | Больше места для истории и устойчивое расположение действий |
| Каждая новая карточка проигрывала входную анимацию | Новые и восстановленные реплики появляются без движения | Частые действия и отправка с клавиатуры не отвлекают от чтения |
| Часть кнопок имела отклик 180 ms | Отклик 140 ms | Соответствует бюджету 100–160 ms для нажатий |
| Кнопка показа пароля была 40×40 px | 44×44 px | Более удобная область нажатия |

Анимация открытия диалога 180 ms с easing cubic-bezier(.23,1,.32,1) сохранена: она обозначает смену контекста. Анимируются opacity и transform. При reduced motion движение отключается, цветовой отклик остаётся. Анимационных проблем, блокирующих проверенные сценарии, после исправлений нет. Verdict review-animations: **Approve** в пределах проверенных сценариев.

| Итого | **15/20 — Good** | Рабочий мобильный интерфейс с обозначенными пределами проверки |

Финальный detector: 0 замечаний вне категории advisory. Остались 65 advisory о несоответствии прежнему DESIGN.md: 38 размеров шрифта, 18 радиусов и 9 цветов. Они не подавлены. Узкое ранее созданное исключение для Inter сохранено; новых исключений нет.

Изменения опубликованы. Проверены активность сервиса, совпадение хэшей 20 файлов приложения, HTTP 200 переводчика, корректность nginx и доступность другого сайта по IP. Перед обновлением сохранены резервные копии. Тестовый аккаунт и его беседа удалены адресно после завершения браузерной проверки.
